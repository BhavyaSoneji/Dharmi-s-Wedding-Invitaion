## Couple photography

`gallery-NN-<world>-*.jpg` — responsive crops (480 / 768 / 1200) made exclusively
from the eleven original photos supplied for the invitation. The crops are 4:5
for the Moments cards.

Source photos, in gallery order: `1L2A1428`, `1L2A1494`, `1L2A1604`, `1L2A1733`,
`1L2A1794`, `1L2A1924`, `1L2A2045`, `1L2A2070`, `1L2A2129`, `1L2A2190`, `1L2A2279`.

`hero-arch-*.jpg` (1200 / 1800 / 2400, 3:2) and `hero-seated-*.jpg`
(480 / 768 / 1200, 2:3) are the art-directed hero pair.

## Audio

`public/wedding-ambient.mp3` is served locally by the music control. Replace
that file to change the soundtrack; the site has no external audio dependency.
